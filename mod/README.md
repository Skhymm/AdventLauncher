# Папка опциональных модов

Сюда кладутся `.zip` архивы модов, которые показываются во вкладке
**«МОДЫ»** внутри лаунчера (не путать с обязательным модпаком, который
синхронизируется с GitHub — это отдельный, дополнительный список).

## Как это работает

- Каждый `.zip`-файл в этой папке — один мод.
- Внутри архива должен лежать один или несколько `.jar`-файлов (можно
  прямо в корне архива, можно во вложенных папках — они всё равно будут
  найдены и установлены).
- При нажатии «Скачать» в лаунчере `.jar`-файлы из архива распаковываются
  в папку модов игры (`<папка игры>/mods`) и попадают в белый список —
  так же, как моды из GitHub-репозитория.
- Название мода в списке берётся из имени файла (например,
  `cool-shaders.zip` → «Cool Shaders»). Чтобы задать красивое имя вручную,
  отредактируйте `manifest.json` рядом с этим файлом.

## Картинка и описание мода (прямо внутри архива)

Просто положите в корень `.zip`-архива (рядом с `.jar`-файлом):

- **`mod.png`** (или `mod.jpg` / `mod.jpeg`) — иконка мода, покажется
  в карточке в лаунчере.
- **`description.txt`** — короткое текстовое описание мода (пара строк),
  тоже покажется в карточке.

Пример структуры архива `cool-shaders.zip`:

```
cool-shaders.zip
├── CoolShaders-1.0.jar
├── mod.png
└── description.txt
```

Оба файла необязательны — если их нет, покажется просто иконка-заглушка
и название без описания.

## manifest.json (необязательно, только для переопределения имени)

```json
{
  "cool-shaders.zip": {
    "name": "Красивые шейдеры",
    "description": "Мягкое освещение и тени"
  }
}
```

## Важно при сборке (electron-builder)

Эта папка уже добавлена в `build.files` в `package.json`, так что при
сборке (`npm run dist`) она попадёт в собранное приложение автоматически.
Просто кладите сюда `.zip`-файлы модов перед сборкой.
